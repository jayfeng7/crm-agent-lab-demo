# CRM Agent Lab · 在线演示

CRM Agent Lab 是我在 Pi Native CRM 基础上独立开发和维护的个人 CRM 项目。这是它的在线演示。

[打开在线演示](https://jayfeng7.github.io/crm-agent-lab-demo/)

可以打开一条示例商机，在「能力实验室」试着整理客户资料、查看工具返回，或确认一项待办操作。「真实模型录制」可以回看两次使用虚构数据的模型运行。

演示使用虚构的客户和商机。回放数据已脱敏，交互在浏览器里执行。完整项目源码存放在私有仓库。
